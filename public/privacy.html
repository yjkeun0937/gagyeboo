앱 소개앱 열기

요약

가계부는 별도의 서버를 운영하지 않습니다. 입력한 가계 데이터는 사용자의 기기와, 사용자가 로그인한 경우 사용자 본인의 구글 드라이브에만 저장되며, 개발자를 포함한 제3자에게 전송되거나 공유되지 않습니다.

1. 앱이 접근하는 구글 사용자 데이터

구글 계정으로 로그인하면 다음 권한을 요청합니다.

  • 이메일 주소·프로필(이름, 사진) (openid, email, profile): 어느 계정으로 로그인했는지 화면에 표시하고, 재연결 때 같은 계정인지 확인하는 용도로만 사용합니다.
  • 구글 드라이브 앱 전용 데이터 폴더 (drive.appdata): 이 앱만 읽고 쓸 수 있는 숨김 폴더입니다. 가계부 데이터 파일(meta.json, entries-연도.json)을 저장하고 불러오는 데에만 사용합니다. 드라이브의 다른 파일은 보거나 변경할 수 없습니다.

2. 데이터가 저장되는 곳

  • 사용자의 기기: 지출 내역·분류·설정은 브라우저의 IndexedDB에 저장됩니다. 로그인 상태(접근 토큰, 계정 이메일·이름)와 화면 설정은 브라우저의 localStorage에 저장됩니다. 접근 토큰은 약 1시간 뒤 만료됩니다.
  • 사용자의 구글 드라이브: 로그인한 경우에 한해 앱 전용 숨김 폴더에 가계부 데이터가 저장됩니다.
  • 그 밖의 서버, 데이터베이스, 분석 도구, 광고 도구는 사용하지 않습니다.

3. 이용 목적과 공유

구글 사용자 데이터는 위 1항의 기능을 제공하는 목적으로만 사용합니다. 판매하거나 광고에 사용하지 않고, 제3자에게 제공하지 않으며, 사람이 열람하지 않습니다. 이 앱의 구글 API 데이터 사용은 Google API 서비스 사용자 데이터 정책(제한된 사용 요구사항 포함)을 따릅니다.

4. 보관 기간과 삭제

  • 앱에서 로그아웃하면 「이 기기 데이터도 삭제」를 선택해 이 기기의 데이터를 지울 수 있습니다.
  • 구글 계정의 서드 파티 앱 및 서비스 연결 관리에서 이 앱의 접근 권한을 언제든 취소할 수 있습니다.
  • 드라이브에 저장된 앱 데이터는 구글 드라이브 설정의 「앱 관리」에서 이 앱의 숨김 데이터를 삭제하여 지울 수 있습니다.
  • 브라우저의 사이트 데이터를 삭제하면 이 기기에 저장된 데이터도 지워집니다.
