# 가계부

개인용 가계부 웹앱. 데스크톱·모바일 Chrome에서 쓰며, 데이터는 사용하는 기기의 브라우저(IndexedDB)에 저장됩니다.
구글 계정으로 로그인하면 내 구글 드라이브의 앱 전용 숨김 폴더를 통해 기기 간에 동기화됩니다(로그인 없이도 모든 기능을 쓸 수 있습니다).

- 앱 주소: https://yjkeun0937.github.io/gagyeboo/
- 이 저장소는 공개 저장소입니다. **개인 데이터(엑셀·CSV·백업 JSON)와 실명은 절대 올리지 않습니다.**
  앱 소스에는 이름이 들어 있지 않고, 화면 확인용 샘플 데이터는 가상의 이름만 사용합니다.

## 개발

```bash
npm install
npm run dev         # 개발 서버
npm test            # 단위 테스트 (vitest)
npm run build       # 타입 검사 + 빌드 → dist/
npm run preview     # 빌드 결과 미리보기 (http://localhost:4173/gagyeboo/)
```

화면 흐름 점검(빌드 후 `npm run preview`를 띄운 상태에서):

```bash
CHROME=/path/to/chrome node e2e/flows.mjs   # 입력·수정·삭제·필터·백업/복원 흐름
CHROME=/path/to/chrome node e2e/shots.mjs   # 3종 화면 크기 캡처 → e2e/out/ (git 제외)
CHROME=/path/to/chrome node e2e/r3flows.mjs # 로그인·동기화 흐름 (가짜 구글 서버로 두 기기 시뮬레이션)
```

## 구성

- Vite + TypeScript + Preact (+ signals), Dexie(IndexedDB)
- `src/lib` 순수 로직(날짜·집계·필터), `src/store` 저장소, `src/ui` 공통 화면 요소, `src/views` 화면
- 배포: `main`에 푸시하면 GitHub Actions가 GitHub Pages로 배포합니다.

## 구글 로그인·동기화 (R3)

### 한 번만 하는 준비: OAuth 클라이언트 ID 만들기

구글 로그인은 앱마다 클라이언트 ID가 있어야 동작합니다(개인 계정으로 만들면 되고 비용은 들지 않습니다).
앱의 **설정 → 계정·동기화**에도 같은 안내가 있습니다.

1. [구글 클라우드 콘솔](https://console.cloud.google.com/)에서 새 프로젝트를 만듭니다.
2. 「API 및 서비스 → 라이브러리」에서 **Google Drive API**를 사용 설정합니다.
3. 「Google Auth Platform(OAuth 동의 화면)」: 사용자 유형 **외부**, 앱 이름·이메일 입력, 데이터 액세스(범위)에
   `openid`, `email`, `profile`, `https://www.googleapis.com/auth/drive.appdata` 추가.
4. 게시 상태를 **프로덕션으로 게시**합니다. 테스트 상태로 두면 7일마다 로그인이 만료됩니다.
5. 「사용자 인증 정보 → OAuth 클라이언트 ID」: 유형 **웹 애플리케이션**,
   승인된 JavaScript 원본에 `https://yjkeun0937.github.io` (경로·슬래시 없이) 추가.
6. 만들어진 클라이언트 ID를 앱의 설정 → 계정·동기화에 붙여 넣고 저장합니다(그 기기에만 저장).

모든 기기에 한 번에 적용하려면 저장소의 Settings → Secrets and variables → Actions → **Variables**에
`GOOGLE_CLIENT_ID`를 만들고 값을 넣은 뒤 다시 배포합니다. 클라이언트 ID는 비밀번호가 아니라 공개되어도 되는 값입니다.

### 동기화 방식

- 드라이브의 **앱 전용 숨김 폴더**(appDataFolder)에만 저장합니다. 드라이브의 다른 파일은 볼 수 없고, 별도 서버를 거치지 않습니다.
  파일은 `meta.json`(목록·설정)과 연도별 `entries-YYYY.json`(내역)입니다.
- 입력은 항상 이 기기에 먼저 저장되고, 몇 초 뒤 묶어서 올라갑니다. 앱을 열 때·다른 화면에서 돌아올 때·켜 둔 동안 주기적으로·
  수동 버튼으로 드라이브의 변경을 받아 옵니다. 오프라인에서도 입력할 수 있고, 연결되면 올라갑니다.
- 같은 항목을 두 기기에서 고쳤다면 **나중에 고친 쪽**이 남습니다(항목 단위). 삭제도 다른 기기에 전달됩니다.
- 처음 로그인할 때 이 기기와 드라이브에 모두 데이터가 있으면 합치기 전에 건수를 보여주고 확인을 받습니다.
- 월간 목표·오늘 이후 내역 표시 방식은 기기 간에 공유하고, 테마·글자 크기·정렬 방식은 기기마다 따로 둡니다.
- 로그인은 약 1시간 뒤 만료됩니다(별도 토큰 서버가 없기 때문). 만료되면 상단 칩이 「재연결 필요」로 바뀌고, 한 번 누르면 이어서 동기화합니다.
- 로그아웃할 때 이 기기의 데이터를 남길지 지울지 고를 수 있습니다. JSON 백업·복원은 그대로 쓸 수 있습니다.
