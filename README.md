# 가계부

개인용 가계부 웹앱. 데스크톱·모바일 Chrome에서 쓰며, 데이터는 사용하는 기기의 브라우저(IndexedDB)에 저장됩니다.
구글 계정으로 로그인하면 내 구글 드라이브의 앱 전용 숨김 폴더를 통해 기기 간에 동기화됩니다(로그인 없이도 모든 기능을 쓸 수 있습니다).

- 앱 주소: https://yjkeun0937.github.io/gagyeboo/
- 이 저장소는 공개 저장소입니다. **개인 데이터(엑셀·CSV·백업 JSON)와 실명은 절대 올리지 않습니다.**
  앱 소스에는 이름이 들어 있지 않고, 화면 확인용 샘플 데이터는 가상의 이름만 사용합니다.

## 개발

```bash
npm install
npm run dev         # 개발 서버
npm test            # 단위 테스트 (vitest)
npm run build       # 타입 검사 + 빌드 → dist/
npm run preview     # 빌드 결과 미리보기 (http://localhost:4173/gagyeboo/)
```

화면 흐름 점검(빌드 후 `npm run preview`를 띄운 상태에서):

```bash
CHROME=/path/to/chrome node e2e/flows.mjs   # 입력·수정·삭제·필터·백업/복원 흐름
CHROME=/path/to/chrome node e2e/shots.mjs   # 3종 화면 크기 캡처 → e2e/out/ (git 제외)
CHROME=/path/to/chrome node e2e/r3flows.mjs # 로그인·동기화 흐름 (가짜 구글 서버로 두 기기 시뮬레이션)
CHROME=/path/to/chrome node e2e/r4flows.mjs # 엑셀 가져오기·내보내기 (가상 파일을 만들어 확인. LEDGER=실제파일.xlsx를 주면 그 파일로도 확인)
CHROME=/path/to/chrome node e2e/r5flows.mjs # 검색·정렬·캘린더·분류별 예산·휴대폰 키보드 스크롤
CHROME=/path/to/chrome node e2e/pwa.mjs     # 설치 정보·오프라인 실행·새 버전 안내 (자체 서버를 띄우고 시험 중 다시 빌드함. 시험 뒤 npm run build로 되돌릴 것)
CHROME=/path/to/chrome node e2e/r5shots.mjs # R5 화면 캡처 → e2e/out/
CHROME=/path/to/chrome node scripts/make-icons.mjs  # 앱 아이콘 PNG 다시 만들기 (public/icons)
```

## 구성

- Vite + TypeScript + Preact (+ signals), Dexie(IndexedDB)
- `src/lib` 순수 로직(날짜·집계·필터), `src/store` 저장소, `src/ui` 공통 화면 요소, `src/views` 화면
- 배포: `main`에 푸시하면 GitHub Actions가 GitHub Pages로 배포합니다.

## 구글 로그인·동기화 (R3)

### 한 번만 하는 준비: OAuth 클라이언트 ID 만들기

구글 로그인은 앱마다 클라이언트 ID가 있어야 동작합니다(개인 계정으로 만들면 되고 비용은 들지 않습니다).
앱의 **설정 → 계정·동기화**에도 같은 안내가 있습니다.

1. [구글 클라우드 콘솔](https://console.cloud.google.com/)에서 새 프로젝트를 만듭니다.
2. 「API 및 서비스 → 라이브러리」에서 **Google Drive API**를 사용 설정합니다.
3. 「Google Auth Platform(OAuth 동의 화면)」: 사용자 유형 **외부**, 앱 이름·이메일 입력, 데이터 액세스(범위)에
   `openid`, `email`, `profile`, `https://www.googleapis.com/auth/drive.appdata` 추가.
4. 게시 상태를 **프로덕션으로 게시**합니다. 테스트 상태로 두면 7일마다 로그인이 만료됩니다.
5. 「사용자 인증 정보 → OAuth 클라이언트 ID」: 유형 **웹 애플리케이션**,
   승인된 JavaScript 원본에 `https://yjkeun0937.github.io` (경로·슬래시 없이) 추가.
6. 만들어진 클라이언트 ID를 앱의 설정 → 계정·동기화에 붙여 넣고 저장합니다(그 기기에만 저장).

모든 기기에 한 번에 적용하려면 저장소의 Settings → Secrets and variables → Actions → **Variables**에
`GOOGLE_CLIENT_ID`를 만들고 값을 넣은 뒤 다시 배포합니다. 클라이언트 ID는 비밀번호가 아니라 공개되어도 되는 값입니다.

### 동기화 방식

- 드라이브의 **앱 전용 숨김 폴더**(appDataFolder)에만 저장합니다. 드라이브의 다른 파일은 볼 수 없고, 별도 서버를 거치지 않습니다.
  파일은 `meta.json`(목록·설정)과 연도별 `entries-YYYY.json`(내역)입니다.
- 입력은 항상 이 기기에 먼저 저장되고, 몇 초 뒤 묶어서 올라갑니다. 앱을 열 때·다른 화면에서 돌아올 때·켜 둔 동안 주기적으로·
  수동 버튼으로 드라이브의 변경을 받아 옵니다. 오프라인에서도 입력할 수 있고, 연결되면 올라갑니다.
- 같은 항목을 두 기기에서 고쳤다면 **나중에 고친 쪽**이 남습니다(항목 단위). 삭제도 다른 기기에 전달됩니다.
- 처음 로그인할 때 이 기기와 드라이브에 모두 데이터가 있으면 합치기 전에 건수를 보여주고 확인을 받습니다.
- 월간 목표·오늘 이후 내역 표시 방식은 기기 간에 공유하고, 테마·글자 크기·정렬 방식은 기기마다 따로 둡니다.
- 로그인은 약 1시간 뒤 만료됩니다(별도 토큰 서버가 없기 때문). 만료되면 상단 칩이 「재연결 필요」로 바뀌고, 한 번 누르면 이어서 동기화합니다.
- 로그아웃할 때 이 기기의 데이터를 남길지 지울지 고를 수 있습니다. JSON 백업·복원은 그대로 쓸 수 있습니다.
- **드라이브의 데이터까지 지우려면:** 설정 → 계정·동기화 → 로그아웃에서 「구글 드라이브에 저장된 가계부 데이터도 모두 삭제」를 체크하고
  버튼을 누릅니다(되돌릴 수 없음, 확인 창이 한 번 더 뜹니다). 다른 기기가 로그인되어 있으면 그 기기의 데이터가 다음 동기화 때 다시 올라가므로,
  그 기기에서도 같은 방법으로 지워야 합니다. 구글 쪽에서 직접 지우려면 드라이브 설정의 「앱 관리」에서 이 앱의 숨김 데이터를 삭제하세요.

## 엑셀 가져오기·내보내기 (R4)

설정 → 데이터 관리 → 「엑셀」. 파일은 브라우저 안에서만 읽고 쓰며 어디로도 보내지 않습니다.

### 가져오기
1. **파일 선택**: `.xlsx`. 월 시트 이름이 `2026-3`처럼 `연도-월` 모양이면 자동으로 선택되고, 그 밖의 시트는 직접 골라야 합니다.
2. **열 인식**: 머리글(`날짜`·`사용처/명세`·`분류`·`금액`·`사용자`·`지불수단`)을 찾아 열을 정합니다. 머리글이 없는 결제상세 열(지불수단 바로 오른쪽)도 인식합니다. 못 찾거나 틀리면 화면에서 열을 직접 지정합니다.
3. **사용자 확인**: 파일의 사용자 값 중 등록되지 않은 것은 `개인` / `그룹`(구성원 선택) / `기존에 연결` / `비움` 중 하나를 직접 고릅니다. 앱은 개인인지 그룹인지 추측하지 않습니다. 이 앱에서 내보낸 파일이면 `사용자` 시트로 미리 채워 줍니다.
4. **미리보기**: 시트별 건수·합계, 새로 등록될 항목, 오늘 이후 날짜(`[예정]`) 안내, 확인이 필요한 줄(날짜 없음·금액 0원·중복 의심)을 체크로 포함/제외.
5. **확정**: 새 목록과 내역이 한 번에 저장됩니다(중간에 실패하면 아무것도 저장되지 않음).

규칙: 날짜가 빈 줄은 윗줄 날짜를 이어받음 · 금액이 빈 줄은 건너뜀 · 분류·지불수단·결제상세는 내역에 **쓰인 값 중 목록에 없는 것만** 새로 등록 ·
같은 날짜·사용처·명세·금액·사용자·지불수단의 내역이 이미 있으면 중복 의심으로 기본 제외(같은 파일을 다시 가져와도 두 번 들어가지 않음) ·
`월 첫 줄 날짜 없음`은 기본 제외, 포함하면 그 달 1일.
가져온 내역에는 묶음 ID가 붙어, 「마지막 가져오기 되돌리기」로 통째로 지울 수 있습니다(그때 새로 등록한 목록 중 쓰이지 않는 것도 함께).

### 내보내기
- 범위: 전체 / 연도 / 기간. 형식: **월별 시트**(월마다 시트 + 위쪽 월 요약, 연간 「분류별」 시트) 또는 **단순 목록**(한 시트). CSV(UTF-8)도 받을 수 있습니다.
- `상태` 열에 보류·예정·예상을 적고, 요약 합계는 앱과 같이 `[보류]`를 뺍니다.
- `사용자` 시트에 이름·구분(개인/그룹)·그룹 구성원이 들어가, 다시 가져올 때 미리 채워집니다.


## 검색·캘린더·분류별 예산 (R5)

### 검색·필터
- 사용 내역 위쪽 돋보기: 사용처·명세 글자 검색(일치 부분 강조), 분류·사용자·지불수단 칩, **금액 범위**(최소~최대), **기간**(전체 기간 검색에서 시작일·종료일).
- 결과 줄에 `건수 · 합계`가 나오고, 보류 내역은 건수에만 들어가며 합계에서는 빠집니다.
- 표 머리글의 **사용처·분류·금액**을 누르면 그 열 기준으로 한 줄씩 정렬합니다(날짜를 누르면 날짜별 묶음으로 복귀). 휴대폰은 정렬 선택 상자.
- 최근 검색어 8개를 이 기기의 브라우저에만 저장합니다(동기화·백업에 들어가지 않음).
- 키보드 단축키는 없습니다.

### 캘린더 보기
- 월 이동 줄의 버튼으로 목록↔캘린더 전환. 설정 → 화면 → 「사용 내역 기본 보기」로 시작 화면을 고릅니다(기기마다 따로 저장).
- 날짜 칸: 하루 합계(보류 제외, 예정 포함), 많이 쓴 날일수록 진한 배경, 금액이 큰 분류 색 점 최대 3개, 보류·예정 표시. 오늘 이후 항목 숨김 설정과 무관하게 항상 보입니다.
- 날짜를 누르면 그날 내역(휴대폰은 달력 아래, 컴퓨터는 오른쪽)과 「이 날 지출 입력」. 필터를 걸면 달력에도 적용됩니다.

### 분류별 예산
- 설정 → 분류별 예산: 분류마다 한 달 한도(모든 달 동일, 이월 없음). 한도는 분류 기록(`Category.budget`)에 들어 있어 구글 드라이브 동기화·백업에 함께 갑니다.
- 사용 내역의 분류 칩에 진행률 바·%, 80% 이상 주의색, 100% 초과는 빨간 `!`. 통계(월간)에 「예산 대비 사용」 카드. 사용액은 앱 집계와 같습니다(보류 제외, 예정 포함).
- 엑셀 내보내기에는 한도를 넣지 않습니다.

### 휴대폰 키보드
- 글자 입력란을 누르면 입력란(과 이름표)이 보이는 영역의 맨 위쪽에 오도록 스크롤합니다. `viewport`의 `interactive-widget=resizes-content`로 키보드가 올라오면 화면 높이가 줄어, 아래에서 올라오는 입력창이 키보드 위에 붙습니다.

## 지출 입력 창·전체 기간 통계 (R5 이후 사양 변경)

- 지출 입력 창의 순서: 날짜 → 사용처 → 명세 → **금액** → 분류 → 사용자 → 지불수단 → 결제상세.
- 금액 칸은 `+`(더하기)와 `*`(곱하기)를 쓴 수식을 받습니다. 곱하기를 먼저 계산합니다. `500+1000` → 1,500, `100*5+200` → 700. 쉼표·공백은 무시하고, 입력하는 동안 `= 결과원`을 미리 보여 줍니다. 휴대폰에서는 `+` / `×` 버튼과 전화번호 자판(`+`가 있음)을 씁니다. 계산 규칙은 `src/lib/amount.ts`.
- 잘못된 수식(`500++3`, `5-3`, 소수점 등)이나 99억 9천만 원이 넘는 값은 저장/저장 후 계속 입력/Enter 때 경고 팝업을 띄우고 저장하지 않습니다. 팝업은 누르면 바로 사라지고 놔두면 약 3초 뒤 사라집니다.
- 「저장 후 계속 입력」은 저장한 뒤 **명세와 금액(과 [예상] 표시)만** 비우고, 날짜·사용처·분류·사용자·지불수단·결제상세는 그대로 둡니다. 포커스는 명세로 갑니다.
- 통계 → 「전체 기간」(연간과 기간 지정 사이): 수집된 모든 내역(보류 제외, 예정 포함)을 대상으로 전체 합계·월평균·지출이 가장 많은 달·가장 많은 항목(분류), 연도별 요약(연 합계·월평균·가장 많은 달·가장 많은 항목), 분류 × 연 지출표를 보여 줍니다. 표의 칸을 누르면 그 해·분류의 내역(전체 기간 검색)으로 이동합니다. 계산은 `src/lib/stats.ts`의 `allPeriodStats`.

## 앱 설치·오프라인 (PWA)

- `public/manifest.webmanifest`(이름·아이콘·표시 방식), `sw/sw.template.js`(서비스 워커 원본). 빌드할 때 `vite.config.ts`의 플러그인이 앱 파일 목록과 버전(파일 이름의 해시에서 계산)을 채워 `dist/sw.js`를 만듭니다.
- 앱 파일은 설치(첫 방문) 때 저장하고 이후엔 저장된 것을 먼저 씁니다 → 인터넷 없이 열리고 입력됩니다. 글꼴 조각은 쓸 때 저장하므로 오프라인에서 처음 쓰는 글자는 시스템 글꼴로 대신 보일 수 있습니다.
- 새 버전을 배포하면 백그라운드에서 받아 두고, 화면 위쪽 안내의 「새로고침」을 누르면 바뀝니다(쓰는 도중에 저절로 바뀌지 않음). 앱을 다시 볼 때와 1시간마다 새 버전을 확인합니다.
- 구글 로그인·드라이브 등 다른 주소의 요청은 서비스 워커가 건드리지 않습니다.
- 설정 → 앱 정보에 「앱으로 설치」 버튼(크롬이 허용할 때)과 안내가 있습니다.
